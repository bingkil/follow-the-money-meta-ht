# Project instructions

Use uv for Python and npm for the web app; commit both lockfiles. Read docs/design.md and docs/implementation.md before changing product behaviour. Keep docs/status.md accurate.

Source records and exact calculations establish evidence. Models interpret tool results. Preserve legal entity boundaries, attribution limits and unknown external activity. Never expose hidden fixture ground truth to agents or label synthetic findings as proof of trafficking.

Keep credentials in environment configuration. Do not commit local databases, customer data or API keys. Run backend tests, Ruff checks and the web production build for relevant changes.
